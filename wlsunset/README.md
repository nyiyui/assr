This module adjusts screen temperature based on time-of-day and device location for Wayland systems that are supported by [wlsunset(1)](https://sr.ht/~kennylevinsen/wlsunset/).

Options:
- `assr.wlsunset.enable`
- `assr.wlsunset.temperature.day` temperature at daytime in Kelvin, defaults to 6500 K
- `assr.wlsunset.temperature.night` nighttime, defaults to 2000 K
